# ChainState

ChainState: a distributed, in-memory data processing engine that manages scalable, persistent workloads in real-time.

ChainState is aimed at developers who need a straightforward, dependable solution.

- python

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ChainState.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

ChainState is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
